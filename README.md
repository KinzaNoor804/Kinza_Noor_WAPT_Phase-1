# Web Application Penetration Testing (WAPT) — Phase 1

## Overview

This repository contains my practical learning tasks, lab exercises, and reports completed during Phase 1 of my Web Application Penetration Testing (WAPT) training.

The objective is to develop foundational web security skills, understand common web vulnerabilities, and gain hands-on experience with penetration testing tools and techniques in authorized lab environments.

## Repository Structure

### 1. Web Fundamentals
- HTTP and HTTPS fundamentals
- HTTP requests and responses
- HTTP methods and status codes
- Cookies, sessions, and web application basics

### 2. Reconnaissance & Enumeration
- Passive reconnaissance
- Active reconnaissance
- Web content discovery
- Information gathering and enumeration

### 3. Burp Suite
- Introduction to Burp Suite
- Intercepting and analyzing HTTP traffic
- Working with Burp Suite Repeater
- Request and response manipulation

### 4. Common Web Vulnerabilities
- Introduction to web application vulnerabilities
- Insecure Direct Object References (IDOR)
- Vulnerability identification and analysis
- Practical exploitation exercises in controlled labs

## Tools & Platforms

- **Burp Suite** — Web application security testing
- **Kali Linux** — Penetration testing environment
- **TryHackMe** — Guided cybersecurity labs
- **PortSwigger Web Security Academy** — Practical web security labs
- **Browser Developer Tools** — Inspecting web requests and responses

## Learning Outcomes

Through these exercises, I aim to:

- Understand how web applications communicate.
- Perform basic reconnaissance and enumeration.
- Analyze and modify HTTP requests using Burp Suite.
- Identify common web application security weaknesses.
- Document practical findings in structured reports.

## Disclaimer

All security testing documented in this repository is performed for educational purposes in authorized lab environments. No unauthorized testing is intended or encouraged.
